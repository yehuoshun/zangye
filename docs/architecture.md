# 架构设计

## 整体架构

```
┌─────────────────────────────────────────────┐
│                 浏览器                        │
│        Vue 3 + TypeScript + Vite 6           │
└──────────────────┬──────────────────────────┘
                   │ HTTP / JSON
                   ▼
┌─────────────────────────────────────────────┐
│              Go HTTP Server                  │
│           net/http (标准库)                   │
├──────────────────┬──────────────────────────┤
│   Middleware     │     CORS                  │
├──────────────────┼──────────────────────────┤
│   Handler        │     路由 + 请求处理        │
├──────────────────┼──────────────────────────┤
│   Service        │     业务逻辑              │
├──────────────────┼──────────────────────────┤
│   Repository     │     SQL 操作              │
├──────────────────┼──────────────────────────┤
│   Database       │     MySQL 8.0            │
└──────────────────┴──────────────────────────┘
```

## 分层职责

### Handler 层 (Controller)
- HTTP 请求/响应处理
- 参数解析和校验
- 调用 Service 层
- 统一响应格式

### Service 层 (Business Logic)
- 业务逻辑编排
- 事务管理
- 跨 Repository 调用

### Repository 层 (Data Access)
- 纯 SQL 操作
- 参数化查询防注入
- 数据模型映射

## 关键设计决策

1. **无第三方框架**：后端使用 Go 标准库 net/http，降低依赖
2. **单 exe 部署**：前端通过 go:embed 嵌入，编译为单个可执行文件
3. **软删除**：文件删除标记 deleted_at 而非物理删除
4. **树形结构**：文件夹一次性全加载，内存中组装树
5. **标签颜色**：HSL 随机生成，保证色彩鲜艳均匀
